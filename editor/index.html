PlateUp Layout Editor — Prototype

Layout

Click a tile to place or select. Drag a selected appliance to move it. Hold Shift and click to multi-select. Copy/Paste uses an internal relative-position clipboard; click an empty tile to choose paste origin. Rotation applies to all selected appliances.

Appliance names are illustrative, not verified PlateUp game IDs. This editor does not connect to the game or import PlateUp Tool share links yet.
